# Security Policy / Politica di Sicurezza

## 🇮🇹 Italiano

### Segnalazione di vulnerabilità
Se riscontri una vulnerabilità di sicurezza in EnergyOS (ad esempio un bug nel parsing dati locali o un problema nei report esportati), ti chiediamo cortesemente di **non aprire una issue pubblica**.

Invia una segnalazione riservata via email a:
**[fbxmano@gmail.com](mailto:fbxmano@gmail.com)**

Includi:
- Descrizione dettagliata della problematica riscontrata.
- Passaggi per la riproduzione o file CSV di esempio minimo.
- Valutazione dell'impatto potenziale.

### Politica di disclosure coordinata
Adottiamo una finestra di disclosure coordinata di **90 giorni**:
1. Conferma di ricezione entro 48 ore.
2. Analisi e aggiornamenti regolari sullo sviluppo della correzione.
3. Rilascio della patch prima di qualunque divulgazione pubblica.

---

## 🇬🇧 English

### Reporting a Vulnerability
If you discover a security issue or vulnerability within EnergyOS, please **do not open a public issue**.

Send a detailed report via email to:
**[fbxmano@gmail.com](mailto:fbxmano@gmail.com)**

Please include:
- A thorough description of the issue.
- Step-by-step reproduction instructions or minimal sample CSV data.
- Assessment of potential impact.

### Coordinated 90-Day Disclosure Policy
We adhere to a **90-day coordinated vulnerability disclosure** policy:
1. Acknowledgement of report within 48 hours.
2. Regular status updates on remediation progress.
3. Coordinated security fix published prior to public disclosure.
